Getting Started

Follow these steps to run the app in the iOS simulator:

1. Open the Project

Open MayaTest.xcodeproj in Xcode.

2. Select a Simulator

Choose any iPhone simulator from the device dropdown.

Recommended: iPhone 15 Pro.

3. Run the App

Tap the Play button in Xcode.

Wait for the simulator to launch and the app to start.

4. Login
